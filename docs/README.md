## 設計書の書き方の約束

- 「決定」と「案」を分ける。案には `[案]`、未回答の依存には `[R2-n]` を付ける
- 内部語彙 (英語キー) とプレイヤー向け語彙 (日本語) を分ける。設計書は内部語彙で書き、対応表を 00_vision に置く
- コードを変えるときは設計書を先に直す。乖離を見つけたら設計書側を正として報告する
