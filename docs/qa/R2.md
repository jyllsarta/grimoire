# R2 詳細質問 (回答待ち)

設計書 v1 のレビューと並行して回答してもらう。各問に推奨案を付けた。回答は本ファイルに転記し、設計書 v1.1 に反映する。

## A. ターン構造・眠り・混乱

**Q1.** 眠り中のフリーアクション (装備切替 / アイテム / アビリティ) は可能か。推奨: 不可。攻撃ボタンは「ねむっている」表示になり、押すと手番スキップ → 敵が行動。

**Q2.** 眠りの被ダメ解除の定義。推奨: 「ライフが実際に減った時」に残ターン 0 (全部ブロックして 0 なら解除しない)。毒の自傷ダメージも含める。

**Q3.** 眠り + ねばねば / 眠り + 敵 blitz は、眠りでスキップするだけで順序の意味はない。OK か。

**Q4.** 減衰の位置を「自分の行動の後」に統一する (03)。付与されたターンの終わりには減らず、麻痺 2 は次の 2 回の攻撃で武器不可 (プロト通り)、眠り 1 は手番 1 回スキップ。OK か。

**Q5.** 混乱の詳細案。(a) 付与時に 1 回シャッフル、再付与でまたシャッフル (b) 混乱中は全部 ??? (アイコン・名前・残回数・効果バッジ)。装備の ON/OFF 表示だけは見える (c) ??? のままでも装備 ON/OFF・アイテム・アビリティは使える (d) 混乱中に獲得した物も ??? (e) 解除で表示が戻り、位置はシャッフル後のまま (f) 非戦闘時の整理 (D&D) は混乱中は不可 (g) 混乱中は右クリックの個体説明も出さない。それぞれ OK か。

**Q6.** 共通バステはイベントからも付く想定か (プロトでは「今後イベントでつくかも」)。推奨: eventEffects に `status` を用意し、同じ付与規則を通す。

## B. 固有バステ

**Q7.** 付与の書き方は enemyActions の type = 固有バステの key、value = ターン数。OK か。

**Q8.** 入替ダミー敵: enemies に `kind (normal / placeholder / heroineUnique)` + `slot 1..4` + `characterId`。placeholder は id 1〜4 を予約、ヒロインの固有敵 id は「ヒロイン id × 100 + slot」(人間用の慣習)。OK か。

**Q9.** Lv1 / Lv2 の違いは「敵の強さ + 付与ターン数」で、ステートの key は同じ。OK か。

**Q10.** 固有バステ中にクロスブレイクを受けたら、裏で衣装状態を進める (解除時に反映) か、無視するか。推奨: 裏で進める。

**Q11.** 固有バステ中に別の固有バステが来たら上書き。上書きされた側の「解除時処理」は呼ばない (切れたのではなく置換)。同じ固有バステの再付与はターン上書き。OK か。

## C. 過酷さ・章・エンディング

**Q20.** スターのゲート `clearAny` はノーマルでもハッピーでも達成。ハッピー限定ゲート (`happyAny`) を追加し、bestDelta もノーマル / ハッピーで別に記録する。OK か。
