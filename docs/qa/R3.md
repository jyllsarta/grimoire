## 反映時に私が置いた仮の解釈 (違っていたら指摘を)

- **Q2 の「不自然な作りになっていてはいけない」**: 個別モジュールは書かないが、契約点 (`onTake`、`fire`、`gain` の位置指定、`relic.gained`、`enemy.killed`、`canFlee` / `canRepairCostume` の許可) は M2 で用意した。tale のモジュールを足すときはファイル 1 つとマスタだけで済む
- **Q4 の「どの程度進めたか」**: selftest は「到達した章 (0..4)」の分布と平均を出す。クリア率は参考値
- **Q18 の重み**: `core/domain/shop.js` の定数 `RARITY_WEIGHTS` (通常レリック枠 rarity 1/2/3 = 70/25/5) と `RARE_WEIGHTS` (レア枠 rarity 2/3 = 95/5)
- **Q19**: 幕間にいる間の `healPrice` の base は「次に入る章」(Extra 前の幕間なら Extra Chapter) の `chapters.healPrice`
