# 00 ゲームの骨子と用語

## 一言で

呪いの本を持ち込んできたオラクルちゃんが、呪いを解ける唯一の人間であるおにーさんを頼り、本に呪われたヒロインを助ける物語。
プレイヤー (おにーさん) はヒロインの駒を動かして本の中のダンジョン (= 本の章) を攻略する。
Meteorfall: Krumit's Tale ベンチマークのパネル選択型ローグライク。プロト「シンティラの魔導書」の手触りを本番品質で作り直す。

## 世界観のルール (設計に効くもの)

- 本 (book) はヒロインと 1:1。本 i はヒロイン i の呪い。ヒロインは自分の本にさえ勝てば救われるが、やり込みとして他人の本にも挑める
- 本は章 (chapter) の列。最終章のボスを倒すと本編完走。そこまでの「過酷さ」が本の要求 (閾値) 以上なら幕間を挟んで Extra Chapter に続く。Extra Chapter は通常の章と同じ形で、道中の敵の先に呪い本体がいる。勝てばハッピーエンド、未達ならノーマルエンド。Extra で敗北しても本編完走は記録される
- 過酷さ = 不利イベントを再生した回数 + 状態異常にかかった回数 (衣装状態が変わるクロスブレイクを含む)。重みは config、閾値は本ごと。インゲームに「本の要求」メーターとして常時出す
- 不利イベントは 3 系統: 章の設計として置くもの (落とし穴、回復の泉)、ヒロイン固有のドジ・不運 (章の入替ダミーで置く)、本人の呪われ体質に起因するもの (スターパレットの不利ノードで幕間の抽選に混ざる)
- 本ごとに 1 つ以上の「本のルール」(インゲーム共通効果: 武器の回収コスト +1、防具装備不可、食べ物が 5 戦闘で腐る、など) が常時かかる。本ごとにユニークで都度実装
- ヒロインごとに固有バステが 2 種あり、SD の絵ごと差し替わる。付与してくる敵はヒロインごとに 4 体 (固有1 Lv1/Lv2、固有2 Lv1/Lv2)。章のマスタは「入替ダミー敵」を書き、章を組むときに挑戦中ヒロインの敵に置き換わる。他人の固有バステが飛んできたら付与をスキップする。固有バステ中は衣装の状態と効果がマスクされ、クロスブレイクも効かない
- オラクルちゃんは立ち絵を持つがインゲームでは常時表示しない。スキットに出る。おにーさんは姿なし・テキストのみ
- ヒロインは総入れ替え。マスタは当面デスサイズちゃん (id 1) のみ。素材は tale/xqueens のものを仮に流用する

## 命名規則: character / heroine / player / enemy

| 語 | 使う場面 | 例 |
|---|---|---|
| character | 登場人物の **同一性**。マスタ characters の 1 行を指すところは全部これ。オラクルちゃんも将来の脇役も character | `characterId` (state / セーブ / マスタ列)、`characters` テーブル、`characterUnique` (敵)、`CharacterFigure` / `CharacterDetail`、`assets/characters/<id>/` |
| heroine | **本を持つ character** というアウトゲームの分類と、プレイヤー向けの言葉。コードでは分類の query にだけ出る | `heroines()` = books を持つ characters、メニューの一覧、systemTexts の「ヒロイン」 |
| player | ラン・バトルの **側 (side)**。人間が操作する側 = 挑戦中 character の駒。xqueens・プロトと同じ | `state.player` (駒の状態)、ステップ `player.tick` / `player.strike`、動詞 `damagePlayer`、`statuses.side = player` |
| enemy | もう一方の側 | `enemy.act.*`、`board.panels[].enemy` |
| protagonist | おにーさん (姿なし)。スキットの話者にだけ出る | `skitLines.speaker = protagonist` |

「character」を側の意味で使わない (「character の HP」とは言わない)。「heroine」を state の中で使わない。

## マイルストーン

| # | 内容 | 完了条件 |
|---|---|---|
| M0 | 設計確定 | 本設計書 v1.x をユーザがレビューし、02_state と 03_timeline が承認される |
| M1 | スキャフォールド + 基盤 | electron-vite で起動し、マスタ同期・セーブ・エディション・音・演出配線・テスト・state インスペクタが通る |
