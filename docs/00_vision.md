# 00 ゲームの骨子と用語

## 一言で

呪いの本を持ち込んできたオラクルちゃんが、呪いを解ける唯一の人間であるおにーさんを頼り、本に呪われたヒロインを助ける物語。
プレイヤー (おにーさん) はヒロインの駒を動かして本の中のダンジョン (= 本の章) を攻略する。
Meteorfall: Krumit's Tale ベンチマークのパネル選択型ローグライク。プロト「シンティラの魔導書」の手触りを本番品質で作り直す。

## 世界観のルール (設計に効くもの)

- 本 (book) はヒロインと 1:1。本 i はヒロイン i の呪い。ヒロインは自分の本にさえ勝てば救われるが、やり込みとして他人の本にも挑める
- 本は章 (chapter) の列。最終章のボスを倒すと本編完走。そこまでの「過酷さ」が本の要求 (閾値) 以上なら Extra Chapter に続き、呪い本体と戦って勝てばハッピーエンド、未達ならノーマルエンド
- 過酷さ = 不利イベントを再生した回数 + バトル中に状態異常にかかった回数 (詳細は [R2])
- 本ごとに 1 つ以上の「本のルール」(インゲーム共通効果: 武器の回収コスト +1、防具装備不可、食べ物が 5 戦闘で腐る、など) が常時かかる。本ごとにユニークで都度実装
- ヒロインごとに固有バステが 2 種あり、SD の絵ごと差し替わる。付与してくる敵はヒロインごとに 4 体 (固有1 Lv1/Lv2、固有2 Lv1/Lv2)。章のマスタは「入替ダミー敵」を書き、章を組むときに挑戦中ヒロインの敵に置き換わる。他人の固有バステが飛んできたら付与をスキップする
- オラクルちゃんは立ち絵を持つがインゲームでは常時表示しない。スキットに出る。おにーさんは姿なし・テキストのみ
- ヒロインは総入れ替え。マスタは当面デスサイズちゃん (id 1) のみ。素材は tale/xqueens のものを仮に流用する

## マイルストーン

| # | 内容 | 完了条件 |
|---|---|---|
| M0 | 設計確定 | 本設計書 v1.x をユーザがレビューし、02_state と 03_timeline が承認される |
| M1 | スキャフォールド + 基盤 | electron-vite で起動し、マスタ同期・セーブ・エディション・音・演出配線・テスト・state インスペクタが通る |
| M2 | コアロジック | デスサイズちゃんの本 1 冊が node のテストで完走できる。全状態異常、過酷さ、Extra Chapter、本のルール 1 つ |
| M3 | UI | tale の見た目と演出テンポを Vue で再現し、アウトゲーム (メニュー/ヒロイン詳細/本選択/リザルト) が通る |
| M4 | **本番想定で 1 キャラ分遊べる** | 人間のテストプレイでハッピーエンド到達 |
| 以降 | ヒロイン追加ループ | 1 ヒロイン + 1 本をセットで追加し、過去分との相互バランスを調整 |
